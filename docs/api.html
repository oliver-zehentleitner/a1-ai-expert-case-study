sms_analysis.data.loader.load_dataset(path)[source]¶

Load the SMS Spam Collection from a tab-separated file.

The file format is one message per line:

ham\tGo until jurong point...
spam\tFREE entry in 2 a wkly comp...
Parameters:

path (Path) – Path to the SMSSpamCollection file.

Return type:

SMSDataset

Returns:

Validated SMSDataset.

Raises:

  • FileNotFoundError – If path does not exist.

  • ValueError – If the file contains unexpected data.

Text preprocessing for the SMS Spam Collection dataset.

Several messages contain HTML-encoded tokens such as &lt;URL&gt; and &lt;#&gt;. Their origin is unclear (researcher anonymisation or smartphone copy-paste artefacts) and would need to be verified against the original collection notes. Some messages also contain raw URLs (http://…).

This module normalises all observed forms to consistent semantic tokens so that the model sees the same representation at training time and at inference time. Skipping this step at inference would cause train-serve skew.

Tokens produced¶

__USER__ – @ &lt;URL&gt; or @handle (username / social-media mention) __URL__ – URL placeholder or real URL __NUM__ – numeric placeholder or standalone number

sms_analysis.data.preprocessing.preprocess(text)[source]¶

Normalise a raw SMS text to a clean, model-ready string.

Applies the same transformations at training time and at inference time, preventing train-serve skew.

Parameters:

text (str) – Raw SMS text, possibly containing HTML entities or real URLs.

Return type:

str

Returns:

Normalised text with semantic placeholder tokens.

Examples:

>>> preprocess("follow me @ &lt;URL&gt; ok?")
'follow me __USER__ ok?'

>>> preprocess("Win &lt;URL&gt; now!")
'Win __URL__ now!'

>>> preprocess("I sent you &lt;#&gt; bucks")
'I sent you __NUM__ bucks'

>>> preprocess("Check http://win-prize.com today")
'Check __URL__ today'

>>> preprocess("Good &amp; bad")
'Good and bad'

sms_analysis.analysis.comparison.log_odds_ratio(ham_texts, spam_texts, top_n=20)[source]¶

Rank words by how strongly they lean towards SPAM or HAM.

Uses Laplace (add-one) smoothing so unseen words don’t cause divide-by-zero. A positive log_odds means the word leans towards SPAM; negative means it leans towards HAM.

Parameters:

  • ham_texts (list[str]) – List of HAM message texts.

  • spam_texts (list[str]) – List of SPAM message texts.

  • top_n (int) – Number of top words to return per class.

Return type:

DataFrame

Returns:

DataFrame with columns word, log_odds, ham_count, spam_count, leaning. Contains top_n HAM-leaning rows and top_n SPAM-leaning rows.

sms_analysis.classification.evaluation.evaluate(y_true, y_pred, y_proba=None)[source]¶

Compute a full set of binary classification metrics.

Parameters:

  • y_true (list[str]) – Ground-truth labels ('ham' / 'spam').

  • y_pred (ndarray) – Predicted labels from the classifier.

  • y_proba (ndarray | None) – Optional [p_ham, p_spam] probability matrix — required for ROC-AUC. If omitted, ROC-AUC is set to float('nan').

Return type:

EvaluationResult

Returns:

EvaluationResult with all metrics.

Note on metric choice:

The dataset is imbalanced (86% HAM / 14% SPAM). Accuracy alone is therefore misleading — a model that always predicts HAM scores 86% without learning anything. F1-SPAM and ROC-AUC are the primary metrics to watch.

class sms_analysis.clustering.base.EmbeddingProvider[source]¶

Bases: ABC

Common interface for all embedding backends.

The clustering layer depends only on this interface. Swap Ollama → OpenAI → Azure by changing the provider — zero changes to clustering logic.

Implementing a new provider requires exactly two things: 1. Override embed() to return vectors. 2. Override the dimensions property.

class sms_analysis.clustering.semantic.SemanticClusterer(provider, n_clusters=None)[source]¶

Bases: object

Embed SMS texts and group them by semantic similarity.

The clustering logic is provider-agnostic: it only calls EmbeddingProvider.embed() — swap Ollama, OpenAI, or Azure by passing a different provider instance.

K-means is used for clustering. If n_clusters is not given, the optimal K is selected automatically via silhouette score over a configurable range.

Example:

from sms_analysis.clustering import SemanticClusterer
from sms_analysis.clustering.providers import OllamaProvider

provider = OllamaProvider()
clusterer = SemanticClusterer(provider)
result = clusterer.fit(dataset.texts[:500])
print(result.summary())

Interactive / CLI helpers¶

Interactive CLI helpers — zero-setup UX for first-time users.

Handles: - Prompting for missing secrets (API keys, endpoints) - Offering to persist them to .env - Installing, starting, and pulling models for Ollama

Design rules: - Secrets are collected via getpass (not echoed, not in shell history). - Nothing is written to .env without explicit consent. - --yes skips all prompts by answering “yes” to everything.

sms_analysis.interactive.ensure_ollama(base_url, model, yes)[source]¶

Ensure Ollama is installed, running, and the requested model is available.

Steps:

  1. Installed? — locate the binary; offer to run the setup script if absent.

  2. Running? — ping the API; offer Start / Try again / Abort in a loop.

  3. Model pulled? — check /api/tags; offer to pull if missing.
